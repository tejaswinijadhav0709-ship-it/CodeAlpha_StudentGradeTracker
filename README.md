# 🎓 CodeAlpha Student Grade Tracker

## 📌 About the Project

The Student Grade Tracker is a Java-based application developed as part of my CodeAlpha Java Programming Internship.

The application helps manage student records and academic performance. It allows users to add students, view their marks, calculate average marks, identify the highest and lowest scores, and generate a summary of student performance.

The project includes both a **console-based application and a graphical user interface (GUI)** built using Java Swing.

## ✨ Features

- ➕ Add student details
- 📋 Display student records
- 📊 Calculate average marks
- 🏆 Find the student with the highest marks
- 📉 Find the student with the lowest marks
- 📝 Display a summary of student performance
- 🖥️ Graphical user interface using Java Swing
- ✅ Validate user input
- 🚫 Prevent duplicate roll numbers
- 🧹 Clear input fields in the GUI

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Data Structure:** ArrayList
- **IDE:** IntelliJ IDEA
- **Version Control:** Git
- **Repository Hosting:** GitHub
